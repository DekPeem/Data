นำเข้า AMR จริง (Admin)
ดาวน์โหลดข้อมูล AMR จากเว็บ PEA แล้วคำนวณโปรไฟล์ P/OP/H อัตโนมัติ
← กลับหน้าแรก
⚠️ ต้องรันเว็บนี้ในเครื่องที่มี Google Chrome ติดตั้งอยู่ กรอกแค่ Username/Password เข้าเว็บ AMR ของ PEA + ช่วงวันที่ ก็พอ — ระบบจะตรวจจับประเภทธุรกิจ/อัตรา/KVA ให้เอง อัตโนมัติจากหน้าข้อมูลผู้ใช้ไฟของ PEA (ไม่ต้องเลือก/กรอกเอง เว้นแต่ต้องการกำหนดเอง ให้เปิด "ตัวเลือกขั้นสูง" ด้านล่าง) — ใช้แค่ครั้งเดียวสำหรับงานนี้แล้วทิ้งทันที ไม่ถูกบันทึกลงดิสก์/log ที่ไหนเลย (หรือจะตั้งค่าตัวแปรสภาพแวดล้อม PEA_AMR_USERNAME / PEA_AMR_PASSWORD ไว้เป็นค่า default แทนก็ได้ ดู README) ไฟล์ดิบที่ดาวน์โหลดมา (มีเลขบัญชี/เลขมิเตอร์) จะถูกเก็บไว้ในเครื่องนี้ที่ โฟลเดอร์ amr_downloads/ เพื่อให้รันซ้ำ/นำเข้าเดือนเพิ่มไม่ต้องดาวน์โหลด ของเดิมใหม่ — โฟลเดอร์นี้อยู่ใน .gitignore แล้ว ไม่มีทางหลุดเข้า repo public ได้เด็ดขาด เหมือนหลักการเดียวกับ customers_local.csv ส่วนไฟล์ load_profiles.csv/business_types.csv ที่ commit เข้า repo ยังคงมีแค่ค่าเฉลี่ย P/OP/H แบบไม่ระบุตัวตนเหมือนเดิม
ตั้งค่าการนำเข้า
เว้นว่างได้ถ้าตั้งค่า PEA_AMR_USERNAME ไว้ในเครื่องแล้ว
ใช้ครั้งเดียวสำหรับงานนี้เท่านั้น ไม่ถูกบันทึกลงที่ใดทั้งสิ้น
ต้องติ๊กเอง — หน้าข้อมูลผู้ใช้ไฟของ PEA ไม่มีฟิลด์บอกสถานะนี้ให้ตรวจจับอัตโนมัติได้ ถ้าติดแล้วจะถูกบันทึกแยกโปรไฟล์ต่างหากจากบัญชีที่ไม่ติด Solar ของธุรกิจ+อัตราเดียวกัน เพราะรูปแบบการใช้ไฟช่วงกลางวันต่างกันมาก
ตัวเลือกขั้นสูง — กรอกเองแทนการให้ระบบตรวจจับอัตโนมัติ
เติมให้อัตโนมัติจาก Username ด้านบน (ปกติ username = เลขบัญชี) — ใช้เฉพาะตอนกรอกประเภทธุรกิจ/อัตราเองเท่านั้น โหมดอัตโนมัติจะดึงจากบัญชีของ username ที่ login เสมอ
สถานะการนำเข้า
ประวัติการนำเข้า AMR ในเครื่องนี้
ชื่อบริษัท/นิติบุคคลและเลขบัญชีจริงที่เคยนำเข้าแบบอัตโนมัติจากเครื่องนี้ — ไว้ดูว่า "ทำอะไรไปแล้วบ้าง มีข้อมูลของใครบ้าง" เท่านั้น อ่านจากไฟล์ import_log_local.csv ซึ่งอยู่ใน .gitignore แล้ว ไม่ถูก commit เข้า repo public เด็ดขาด เหมือนหลักการเดียวกับ customers_local.csv
นำเข้าเมื่อ ชื่อบริษัท/นิติบุคคล เลขบัญชี ประเภทธุรกิจ รหัสอัตรา
หมวดหมู่ธุรกิจทั้งหมดในระบบ (แบ่งตาม Section)
จัดกลุ่มตาม Section (TSIC) ก่อน แล้วค่อยแยกเป็น Division/ประเภทธุรกิจย่อยด้านใน — กดที่ Section เพื่อดูรายชื่อบริษัทที่เคยนำเข้าในกลุ่มนั้น และกด "📈 ดูกราฟ" เพื่อดู รูปแบบการใช้ไฟที่นำเข้าจาก AMR จริง (ส่วนนี้ยังไม่ใช่การพยากรณ์ — เป็นขั้นแรกที่นำข้อมูล AMR เข้าระบบและดูว่าประเภทธุรกิจนี้มีรูปแบบกราฟเป็นอย่างไรก่อน) หมวดที่ยังไม่ได้ตรวจสอบ TSIC จะถูกจัดไว้ในกลุ่ม "ยังไม่ตรวจสอบ" — กดปุ่ม "ตรวจสอบ TSIC" ในการ์ดนั้นเพื่อค้นหา และบันทึกได้เลย
