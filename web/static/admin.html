ดาวน์โหลดข้อมูล AMR จากเว็บ PEA แล้วคำนวณโปรไฟล์ P/OP/H อัตโนมัติ
📖 คู่มือการใช้งาน 🧠 วิธีการคิด/โมเดล 📋 รอทราบอัตรา ⚡ จับคู่เฉพาะหมวดธุรกิจ 💾 สำรองข้อมูล ← กลับหน้าแรก
⚠️ ต้องรันเว็บนี้ในเครื่องที่มี Google Chrome ติดตั้งอยู่ กรอกแค่ Username/Password เข้าเว็บ AMR ของ PEA + ช่วงวันที่ ก็พอ ระบบจะตรวจจับประเภทธุรกิจ/อัตรา/KVA ให้เองอัตโนมัติ — ข้อมูล ที่กรอกและไฟล์ที่ดาวน์โหลดมาปลอดภัย ไม่หลุดเข้า repo public อ่านรายละเอียดในคู่มือ →
ฐานข้อมูล DBD Open Data (ค้นชื่อบริษัทแบบออฟไลน์)
เว็บ DBD DataWarehouse และ dataforthai.com บางครั้งบล็อกการค้นหาอัตโนมัติ — ปุ่มนี้ดึงข้อมูลนิติบุคคล "จดทะเบียนใหม่/เลิกกิจการ" ที่ DBD เปิดเผยเป็น Open Data มาเก็บไว้ในเครื่องแทน เพื่อค้นหาได้เร็วโดยไม่ต้องต่อเน็ตทุกครั้ง (ครอบคลุมเฉพาะบริษัทที่ตั้งใหม่/เลิกในช่วงที่ดึง ไม่ใช่ทะเบียนบริษัทเก่าทั้งหมด)
กำลังตรวจสอบ...
ดึงตั้งแต่ปี 2020 ถึงเดือนปัจจุบัน (ใช้เวลาหลายนาที ทำครั้งเดียวหรือกดซ้ำเพื่ออัปเดตได้)
ตั้งค่าการนำเข้า
เว้นว่างได้ถ้าตั้งค่า PEA_AMR_USERNAME ไว้ในเครื่องแล้ว
ใช้ครั้งเดียวสำหรับงานนี้เท่านั้น ไม่ถูกบันทึกลงที่ใดทั้งสิ้น
ต้องติ๊กเอง — หน้าข้อมูลผู้ใช้ไฟของ PEA ไม่มีฟิลด์บอกสถานะนี้ให้ตรวจจับอัตโนมัติได้ ถ้าติดแล้วจะถูกบันทึกแยกโปรไฟล์ต่างหากจากบัญชีที่ไม่ติด Solar ของธุรกิจ+อัตราเดียวกัน เพราะรูปแบบการใช้ไฟช่วงกลางวันต่างกันมาก
ตัวเลือกขั้นสูง — กรอกเองแทนการให้ระบบตรวจจับอัตโนมัติ
เติมให้อัตโนมัติจาก Username ด้านบน (ปกติ username = เลขบัญชี) — ใช้เฉพาะตอนกรอกประเภทธุรกิจ/อัตราเองเท่านั้น โหมดอัตโนมัติจะดึงจากบัญชีของ username ที่ login เสมอ
ใช้ตอนมีไฟล์ AMR จากเว็บ PEA อยู่แล้ว — แนบแค่ไฟล์ก็พอ ไม่ต้องกรอกอะไรเพิ่มเลย ระบบจะอ่านเลขบัญชีจากในไฟล์แล้วหาประเภทธุรกิจ/อัตราจากทะเบียนลูกค้าให้เอง อ่านรายละเอียดในคู่มือ →
