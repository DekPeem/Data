1. ต้องเตรียมอะไรก่อนรันเว็บนี้ / ข้อมูล Username-Password ปลอดภัยแค่ไหน

⚠️ ต้องรันเว็บนี้ในเครื่องที่มี Google Chrome ติดตั้งอยู่ กรอกแค่ Username/Password เข้าเว็บ AMR ของ PEA + ช่วงวันที่ ก็พอ — ระบบจะตรวจจับประเภทธุรกิจ/อัตรา/KVA ให้เอง อัตโนมัติจากหน้าข้อมูลผู้ใช้ไฟของ PEA (ไม่ต้องเลือก/กรอกเอง เว้นแต่ต้องการกำหนดเอง ให้เปิด "ตัวเลือกขั้นสูง" ด้านล่าง) — ใช้แค่ครั้งเดียวสำหรับงานนี้แล้วทิ้งทันที ไม่ถูกบันทึกลงดิสก์/log ที่ไหนเลย (หรือจะตั้งค่าตัวแปรสภาพแวดล้อม PEA_AMR_USERNAME / PEA_AMR_PASSWORD ไว้เป็นค่า default แทนก็ได้ ดู README) ไฟล์ดิบที่ดาวน์โหลดมา (มีเลขบัญชี/เลขมิเตอร์) จะถูกเก็บไว้ในเครื่องนี้ที่ โฟลเดอร์ amr_downloads/ เพื่อให้รันซ้ำ/นำเข้าเดือนเพิ่มไม่ต้องดาวน์โหลด ของเดิมใหม่ — โฟลเดอร์นี้อยู่ใน .gitignore แล้ว ไม่มีทางหลุดเข้า repo public ได้เด็ดขาด เหมือนหลักการเดียวกับ customers_local.csv ส่วนไฟล์ load_profiles.csv/business_types.csv ที่ commit เข้า repo ยังคงมีแค่ค่าเฉลี่ย P/OP/H แบบไม่ระบุตัวตนเหมือนเดิม

2. โหมด "แนบไฟล์ที่มีอยู่แล้ว" ใช้ตอนไหน ทำงานยังไง

ใช้ตอนมีไฟล์ "รายงานข้อมูลกิโลวัตต์ชั่วโมงแบบช่วงเวลา" จากเว็บ AMR ของ PEA อยู่แล้ว (เช่น ได้รับไฟล์มาจากที่อื่น ไม่มี username/password ของบัญชีนั้นเอง) — ต้องเป็นไฟล์ รูปแบบเดียวกับที่โหมดดึงจากเว็บดาวน์โหลดมาให้เอง (นามสกุล .xls ที่จริงๆ เป็นตาราง HTML มีคอลัมน์ RATE A/B/C) แนบได้หลายไฟล์พร้อมกัน (เช่นหลายเดือน) จะถูกเฉลี่ยรวมกัน เหมือนโหมดดึงจากเว็บ — แนบแค่ไฟล์ก็พอ ไม่ต้องกรอกอะไรเพิ่มเลย ระบบจะอ่านเลข บัญชีจากในไฟล์แล้วเทียบกับทะเบียนลูกค้า (customers.csv/customers_local.csv) ให้เอง ถ้าบัญชีนี้เคยลงทะเบียนประเภทธุรกิจ/อัตราไว้แล้วจะดึงมาใช้อัตโนมัติทันที — ถ้าไม่เจอใน ทะเบียนถึงจะต้องกรอกประเภทธุรกิจ/รหัสอัตราเองด้านล่าง (ระบบจะแจ้งเตือนให้ตอนนั้น)

3. "ประวัติการนำเข้า AMR ในเครื่องนี้" เก็บอะไรไว้ ปลอดภัยแค่ไหน

4. หน้า "หมวดหมู่ธุรกิจทั้งหมดในระบบ" จัดกลุ่มยังไง ใช้ทำอะไร

จัดกลุ่มตาม Section (TSIC) ก่อน แล้วค่อยแยกเป็น Division/ประเภทธุรกิจย่อยด้านใน — กดที่ Section เพื่อดูรายชื่อบริษัทที่เคยนำเข้าในกลุ่มนั้น และกด "📈 ดูกราฟ" เพื่อดู รูปแบบการใช้ไฟที่นำเข้าจาก AMR จริง (ส่วนนี้ยังไม่ใช่การพยากรณ์ — เป็นขั้นแรกที่นำข้อมูล AMR เข้าระบบและดูว่าประเภทธุรกิจนี้มีรูปแบบกราฟเป็นอย่างไรก่อน) หมวดที่ยังไม่ได้ตรวจสอบ TSIC จะถูกจัดไว้ในกลุ่ม "ยังไม่ตรวจสอบ" — กดปุ่ม "ตรวจสอบ TSIC" ในการ์ดนั้นเพื่อค้นหา และบันทึกได้เลย

5. ช่อง Section / Division ตอนตรวจสอบ TSIC คืออะไร ใช้ทำไม

TSIC คือระบบจัดหมวดหมู่ธุรกิจมาตรฐานของไทย จัดเป็นลำดับชั้น Section (หมวดใหญ่สุด — ตัวอักษร A-U) → Division (หมวดย่อยลงมา — ตัวเลข 2 หลัก) รหัสประเภทธุรกิจของ กฟภ. (รหัสที่ขึ้นต้นด้วยตัวเลข เช่น 71920) ไม่ใช่รหัส TSIC มาตรฐาน — 4 ช่องนี้คือการ "แปลง" ให้รู้ว่าตรงกับหมวด TSIC ไหน เพื่อเก็บไว้ใช้เฉพาะตอนไม่มีข้อมูล AMR จริงของ ประเภทนี้เลย ระบบจะได้ไปหยิบค่าเฉลี่ยจากประเภทธุรกิจอื่นที่อยู่ Division เดียวกันมาใช้ แทนแบบคร่าวๆ ดีกว่าตกไปใช้ค่ากลางทั่วไป — ถ้าประเภทนี้มีข้อมูล AMR จริงอยู่แล้ว การกรอก/ ไม่กรอกช่องนี้จะไม่กระทบผลพยากรณ์ของประเภทนี้เอง มีผลแค่กับประเภทธุรกิจอื่นที่ยังไม่มีข้อมูล เท่านั้น

6. พิมพ์ชื่อบริษัทในหน้าแรก (พยากรณ์แบบไม่บันทึกข้อมูล) ปลอดภัยแค่ไหน

ℹ️ พิมพ์ชื่อบริษัทได้อย่างอิสระ (แม้เป็นชื่อจริง) เพราะชื่อที่พิมพ์จะไม่ถูกส่งไปที่ เซิร์ฟเวอร์เลย — ใช้แสดงผลในเบราว์เซอร์นี้เท่านั้น ไม่ถูกบันทึกลงไฟล์ ไม่ถูก log ที่ไหนทั้งสิ้น ปิด/รีเฟรชหน้านี้แล้วข้อมูลหายไปทันที

ปุ่ม "🔍 ค้นหาประเภทธุรกิจอัตโนมัติ" เป็นข้อยกเว้นเดียว — ปุ่มนี้จะส่งชื่อบริษัทออกไป ค้นหาที่เว็บสาธารณะของกรมพัฒนาธุรกิจการค้า (DBD) เพื่อดึงประเภทธุรกิจ (TSIC) มาเติมให้ อัตโนมัติ — ต่างจากการกด "พยากรณ์" ที่ไม่ส่งชื่อออกจากเบราว์เซอร์เลย ไม่จำเป็นต้อง กดปุ่มนี้ก็ได้ถ้าอยากเลือกประเภทธุรกิจเอง — ต้องรันเว็บนี้ในเครื่องที่มี Google Chrome ติดตั้งอยู่และมี network ออกอินเทอร์เน็ตได้
