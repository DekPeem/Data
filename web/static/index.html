ระบบพยากรณ์โปรไฟล์การใช้ไฟฟ้า
โครงการ No AMR — สำหรับผู้ใช้ไฟที่ยังไม่มีข้อมูลมิเตอร์ AMR ของตัวเอง
📖 คู่มือการใช้งาน 🧠 วิธีการคิด/โมเดล นำเข้า AMR (Admin) →
ℹ️ พิมพ์ชื่อบริษัทได้อย่างอิสระ (แม้เป็นชื่อจริง) เพราะชื่อที่พิมพ์จะไม่ถูกส่งไปที่เซิร์ฟเวอร์เลย อ่านรายละเอียดในคู่มือ →
ปุ่มนี้จะส่งเลขนิติบุคคล (ถ้ากรอก) หรือไม่ก็ชื่อบริษัทด้านบน ออกไปค้นหาที่ฐานข้อมูล DBD (ไม่จำเป็นต้องกดถ้าอยากเลือกประเภทธุรกิจเอง) อ่านรายละเอียดในคู่มือ →
แสดงเฉพาะประเภทที่มีโปรไฟล์อ้างอิงจริงรองรับแล้วเท่านั้น — ถ้าไม่ทราบรหัสธุรกิจ 5 หลัก เลือกแค่ Section (หมวดใหญ่) ก็พยากรณ์ได้เลย ไม่ต้องเลือกประเภทธุรกิจย่อยต่อ
ตัวเลือกจะเปลี่ยนตามประเภทธุรกิจที่เลือก — มีเฉพาะคู่ที่มีข้อมูลจริงรองรับ (จับคู่ตรง exact match เสมอ) หรือเลือก "ไม่ระบุ" ถ้าไม่ทราบรหัสอัตรา (จะจับคู่แบบประมาณการจากประเภทธุรกิจอย่างเดียวแทน)
ใช้ปรับสเกลผลพยากรณ์ตามขนาดสัญญาจริง ถ้าไม่กรอกจะใช้ค่าดิบของโปรไฟล์อ้างอิง
รูปแบบการใช้ไฟช่วงกลางวันต่างกันมากถ้าติด Solar — เลือก "ไม่ทราบ" จะใช้โปรไฟล์ที่ไม่ติด Solar เป็นค่าเริ่มต้น (ถ้ามีให้เลือก)
ℹ️ จำลองผลของการหยุดเครื่องจักร/หยุดผลิตชั่วคราว (เช่น พักเที่ยง) ต่อกำลังไฟฟ้าและพลังงานที่ใช้ โดยใช้รูปทรงกราฟรายชั่วโมงจริงของประเภทธุรกิจที่เลือกเป็นฐาน แล้วปรับสัดส่วนให้ตรงกับตัวเลข P/OP/H ที่กรอกมา
แสดงเฉพาะประเภทที่มีข้อมูลกราฟรายชั่วโมงจริงจาก AMR ที่นำเข้าไว้แล้วเท่านั้น
หน่วย kW เรียงตามคาบ Peak / Off-Peak / Holiday
หน่วย kWh เรียงตามคาบ Peak / Off-Peak / Holiday
ถึง
รองรับเฉพาะช่วงเวลาที่อยู่ในคาบ Peak (09:00-22:00) เท่านั้น
100% = หยุดเครื่องจักรสนิทในช่วงนั้น, 30% = ลดลงบางส่วน
กรอกข้อมูลด้านบนแล้วกด "พยากรณ์" เพื่อดูผลพยากรณ์
