ระบบพยากรณ์โปรไฟล์การใช้ไฟฟ้า
โครงการ No AMR — สำหรับผู้ใช้ไฟที่ยังไม่มีข้อมูลมิเตอร์ AMR ของตัวเอง
นำเข้า AMR (Admin) →
ℹ️ พิมพ์ชื่อบริษัทได้อย่างอิสระ (แม้เป็นชื่อจริง) เพราะชื่อที่พิมพ์จะไม่ถูกส่งไปที่เซิร์ฟเวอร์เลย — ใช้แสดงผลในเบราว์เซอร์นี้เท่านั้น ไม่ถูกบันทึกลงไฟล์ ไม่ถูก log ที่ไหนทั้งสิ้น ปิด/รีเฟรชหน้านี้แล้วข้อมูลหายไปทันที
แสดงเฉพาะประเภทที่มีโปรไฟล์อ้างอิงจริงรองรับแล้วเท่านั้น
ตัวเลือกจะเปลี่ยนตามประเภทธุรกิจที่เลือก — มีเฉพาะคู่ที่มีข้อมูลจริงรองรับ (จับคู่ตรง exact match เสมอ)
ใช้ปรับสเกลผลพยากรณ์ตามขนาดสัญญาจริง ถ้าไม่กรอกจะใช้ค่าดิบของโปรไฟล์อ้างอิง
กรอกข้อมูลด้านบนแล้วกด "พยากรณ์" เพื่อดูผลพยากรณ์
