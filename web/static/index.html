ค้นหาประเภทธุรกิจ (TSIC)
โครงการ No AMR — จับคู่ชื่อบริษัท/เลขทะเบียนนิติบุคคลกับหมวดธุรกิจในระบบ
📖 คู่มือการใช้งาน 🧠 วิธีการคิด/โมเดล Admin →
ℹ️ พิมพ์ชื่อบริษัทได้อย่างอิสระ (แม้เป็นชื่อจริง) เพราะชื่อที่พิมพ์จะไม่ถูกบันทึกไว้ที่ไหน — แต่ถ้ากดปุ่มค้นหาด้านล่าง ชื่อ/เลขทะเบียนจะถูกส่งไปค้นหาที่เว็บ DBD DataWarehouse จริง อ่านรายละเอียดในคู่มือ →
ปุ่มนี้จะส่งเลขนิติบุคคล (ถ้ากรอก) หรือไม่ก็ชื่อบริษัทด้านบน ออกไปค้นหาที่ฐานข้อมูล DBD (ไม่จำเป็นต้องกดถ้าอยากเลือกประเภทธุรกิจเอง) อ่านรายละเอียดในคู่มือ →
ค้นหาอัตโนมัติด้านบนจะเลือกให้เองถ้าเจอ — หรือเลือกเองจากรายการทั้งหมดในระบบได้เลย ถ้าไม่เจอรหัสที่ต้องการ เพิ่มประเภทธุรกิจใหม่ได้จากหน้า Admin
ℹ️ นี่คือ "รูปทรง" เส้นโค้งที่สร้างขึ้นให้ดูสมเหตุสมผลจากตัวเลขบนบิลของคุณเอง (Peak + หน่วยไฟ) เท่านั้น — ไม่ใช่การวัดจริง และไม่ได้อิงข้อมูลจริงของบริษัทอื่น กรอกอย่างน้อย 1 ช่วง (P, OP หรือ H) ก็พยากรณ์ได้แล้ว อ่านวิธีการคิด →
